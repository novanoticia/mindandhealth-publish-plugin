## How to propose internal links

When writing a new article:

1. Search the vault (`website/*.md`) for related articles.
2. Propose 2–5 internal links in this format:

   ```markdown
   [Article title](https://mindandhealth.org/website/filename-without-md)
   ```

3. Integrate links naturally where the argument calls for them rather than listing them at the end.
4. If no clear links exist, **do not invent them**. None is better than forced links.

## URL convention

`https://mindandhealth.org/website/[filename-without-extension]`

Example: `reflexion_practicas_eticas.md` → `https://mindandhealth.org/website/reflexion_practicas_eticas`
