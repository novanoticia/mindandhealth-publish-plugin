# 1.3.1 — Complete the i18n resource layer

Version 1.3.0 added multilingual guides and language instructions, but it did not include fixed-text localization catalogs. This patch adds them and connects them to the existing editorial workflow.

- `i18n/es.json` is the canonical Spanish catalog; `en.json`, `fr.json`, and `zh-CN.json` provide equivalent fixed prompts and labels.
- The skill loads the selected catalog and retains Spanish as the default. Missing translations fall back to a complete Spanish response rather than mixing languages.
- Glossary, review status, and Spanish-source SHA-256 fingerprints make the resources maintainable.
- Packaging includes JSON catalogs in the self-contained chat ZIP and verifies parity with the plugin sources.
- Tests reject missing or extra keys, changed placeholders, altered technical literals, stale translations, duplicate JSON keys, empty strings, invalid Unicode normalization, and unsupported claims of human review.

The fixed-message wording is newly consolidated. Article prose and ethical footers remain freshly generated. Translations are AI drafts; human linguistic review and real platform evaluation remain pending. No ZIP is committed to main; download the attached bundle.
